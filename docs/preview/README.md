# Prévia navegável sem instalação

Baixe **wireframe.html** e abra o arquivo no Chrome ou Edge. Não requer Node, servidor ou conexão depois do download.

Contém 37 telas/variantes capturadas do wireframe real, com menu e links entre telas. A barra superior permite escolher telas e estados. Menu fixo e carrosséis funcionam no navegador.

É uma prévia estática navegável do perfil Essencial: formulários, filtros, abas, login, compras e downloads de materiais estão inativos. Não substitui o projeto React nem simula autenticação. A paleta final continua separada nos documentos de design.

Gerar novamente: inicie npm run dev e execute npm run preview:offline. Nenhum deploy foi realizado.

Download alternativo: wireframe.zip contém somente wireframe.html. Extraia e abra o HTML.

Verificado sem rede em 1440px e 390px: navegação produto/módulo, seleção de estado, menu fixo e Escape. Lint e tipos passaram.
